# 听写、委派与集成验收

复用 Pi 的录音器、草稿和截图交互。约 43 MB 的多语言 Whisper 模型数据在构建时按固定版本下载并校验 SHA-256；WASM 推理在扩展专用工作线程内运行。推理完成、失败或取消后释放线程。此选择使用户只需安装扩展，录音不会发出设备。

- 听写检查使用合成麦克风语音和实际 Whisper 推理。关闭或取消权限页后可重新发起，授权后可以录音、收起浮窗并返回。通过暂时移开隔离测试扩展的一份模型文件制造转写失败，确认能回听录音、恢复模型后重试并将文字接到原草稿，再次录音并取消可保留原文字。
- 讨论检查使用真实 Pi Agent SDK 和隔离的模型传输替身，验证截图作为图片消息保存、公式渲染、引用回答、共享模型设置、引导与下一轮排队、独立分叉、委派、交互提问和页面笔记操作。用正常浏览器操作打开原生侧栏，检查草稿交接。显式终止后台工作线程后，侧栏仍能接回任务并停止。
- 在同一已保存讨论同时打开浮窗与侧栏时，录音归发起视图；显式转入侧栏时移交。回填结果使用录音标识确认，允许交付重试。第三轮 simplify 还修复了并发录音归属、麦克风授权撤销、来源关闭期间的子任务启动以及委派等待时限。
- 实际导出的 JSON 可在来源标签关闭后读取，重复来源标签不会推迟清理。本地文件检查覆盖浏览器文件权限、HTML 草稿失败保留、本地 PDF 刷新及撤销权限后的反馈。
- 已在仓库外的新目录用锁文件安装依赖，重新获取并校验模型，独立构建并在隔离浏览器通过 PDF 阅读检查。最终在当前目录和第二个全新目录中分别运行了完整的 `npm run check`，两次均通过。

OpenAI 为首版唯一目标提供方。测试构建单独替换账户与模型传输，生产构建不生成测试凭据。真实订阅首次登录、模型请求、刷新与退出需待 OpenAI 的纯扩展授权条件明确后验收。
