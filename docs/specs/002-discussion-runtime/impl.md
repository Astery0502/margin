# 执行、讨论与页面管理

从正常扩展构建复制一个临时版本，仅在测试构建中替换模型传输。测试构建使用独立的授权替身，实际执行由 Pi Agent SDK、离屏文档和专用工作线程完成。生产构建未接入合成回复。OpenAI 真实授权仍有缺口。

`node checks/discussions.mjs` 在隔离 Edge 中验证 HTML 两个 Full 选区共享模型历史、快照只保存一次、执行时关闭浮窗、侧栏接回并停止、定位回原段落、工具提问及回答、页面笔记写入与清空、归档恢复、按来源标题检索、导出数据及来源关闭清理。刷新页面保留历史。设置页可以增选 Agent 并保存默认模型、指令和工具。

本轮 simplify 修正普通追问的选段语义、同页相同快照去重、并行交互请求互相覆盖、删除与关闭来源的竞态、通知投递和任务异常退出恢复。流式刷新通过游标只读取消息后缀。重新构建后受控任务、PDF 阅读器、浮窗检查均通过。下一步扩大正常浏览器入口覆盖，接回听写、委派，核对侧栏真实交接、队列、分叉与后台挂起。

Pi 工作树在 Agent 和运行时上的未提交改动涉及本机工作区的 webAccess 参数及继承。Margin 采用已提交的委派操作语义；浏览器按 Agent 允许的阅读工具执行，无需继承终端配置。
