# macOS 订阅连接实现记录

本轮沿用 Pi 基线 `84cb7a9` 迁入的阅读、讨论和 Agent。OpenAI 订阅认证由新组件 Margin Connect 承担。macOS 用户从草稿发起连接时，在安装包和 OpenAI 页面各确认一次，接着回到原草稿，按发送才调用模型。

## 运行边界

扩展持有讨论、队列、工具和页面数据。专用工作线程继续使用 Pi 的 Responses 适配器，通过离屏页面转交给扩展后台，再由后台通过原生消息端口提交模型请求。每条流有独立端口，停止时释放本机请求。

组件仅向指定提供方发起请求。首次注册使用安装级标识与 Margin 应用名，回环监听就绪后才打开授权页。身份校验使用 Go OIDC 库。组件按已签发的客户端标识保存注册信息，通过文件锁和原子替换轮换凭据。当前采用权限为 `0600` 的本机凭据文件，目录为 `0700`。退出后保留再次授权所需的注册信息。

## 验收入口

- `npm run build:mac` 构建包含两个架构的安装包以及带安装入口的扩展。开发签名用于本地构建。
- `npm run check:connect` 在隔离的 Edge 中运行实际扩展、原生消息与 OIDC 验证。测试专用组件把提供方流量指向本机签名与模型夹具。
- `npm run check` 复验阅读器、讨论执行、本地文件和听写。
- 发布验收使用真实商店标识、Developer ID 签名及经公证的下载包。用户用自己的账户完成授权、PDF 讨论、刷新和撤销后，才能勾选真实订阅验收。Intel 构建的运行表现还需在 Intel Mac 上实测。

隔离验收已覆盖错误回调状态、签名有效但随机数不匹配的身份令牌、复用已签发的客户端标识重试、流式回答中退出、再次授权、凭据轮换以及重启后退出。模型服务按订阅接口的字段与工具要求检查请求。公开下载渠道与真实订阅仍待验收。
