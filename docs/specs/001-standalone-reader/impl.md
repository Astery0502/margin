# 独立阅读器迁移记录

Pi 基线为 `84cb7a963a7a2da9e17725dde9635289fec81582`。使用该提交的浏览器阅读器、讨论视图、公式资源、浮窗检查和示例 PDF。相关路径与 Pi 工作树一致。Margin 独立声明依赖，构建产物在 `dist/`。

在隔离的 Edge 配置中，`npm run check:reader` 验证了带登录态的 PDF 文件交接、关闭原生标签后从缓存刷新、选段打开 Full 草稿、旋转和放大后返回原段落、关闭阅读器清理缓存。`npm test` 验证浮窗的尺寸与位置。每次验证均未启动 Pi 工作区。

本轮 simplify 将全文读取推迟到首次发送，避免为空页反复生成标记覆盖层，恢复旧版选段匹配和侧栏检索规则，收紧按来源读取与事件投递，修复无效阅读器地址影响其他标签页初始化的问题。独立构建和上述两组检查已重新通过。

首版提供方由仓库所有者确定为 OpenAI。[开源客户端的订阅授权说明](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) 要求在 HTTP 回环地址启动监听器；[Chromium 的直接套接字说明](https://developer.chrome.com/docs/iwa/direct-sockets) 将监听能力限制在隔离式网页应用。普通扩展适用的订阅授权配置仍待确认。暂不切换提供方，真实订阅登录、推理、刷新与退出留作待验收项。后续先迁入扩展内任务执行与讨论存储，并用受控回复验收视图和来源寿命。
